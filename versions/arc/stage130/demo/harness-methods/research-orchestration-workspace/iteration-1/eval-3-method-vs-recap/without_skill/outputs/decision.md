# 下一步研究调度决策

## 决策

开启一条短期、假设驱动的研究线，研究对象是：**如何根据动作前后帧及动作结果识别受控对象，并可靠地区分 HUD/计数器动画、真实移动和碰撞导致的零位移**。研究产物必须是可执行、可证伪的识别流程，而不是“三次看到了什么”的轨迹复述。

先建立一次性的干净 child 上下文，不立即创建持久 subagent。child 只读接收材料并做离线分析；它不能操作游戏、请求回放或把未经验证的判断直接装配给主 agent。主 agent 仍独占后续所有游戏动作。

## 输入与证据边界

给 child 提供带稳定编号的动作前后帧，以及最少的事实标签：发出的动作、动作是否成功返回、是否发生碰撞迹象。材料至少覆盖：

1. 两个“最大变化块确实可能是受控对象”的正例；
2. 一个“最大变化块其实是计数器动画”的反例；
3. 一个“发出方向动作但对象因碰撞而不动”的零位移例；
4. 若存在，额外提供完全无动作或仅 HUD 变化的负对照。

不要把“最大变化块就是自己”作为事实写入上下文，只把它列为待检验假设。现有四类片段来自同一段游戏，其结论最多是当前 episode 的候选规律，不能自动外推到其他 level 或游戏。

## 分解

### 1. 候选生成

让 child 对每组前后帧提取所有变化连通块及不变但可能属于对象的邻近区域，记录位置、边界框、颜色/形状、面积和位移。HUD 区域不能仅凭“小”或“固定”先验被提前删除。

### 2. 竞争假设与反例审查

至少比较以下解释：最大变化块、与动作方向一致的成对消失/出现结构、跨帧保持外观的候选、固定屏幕区域动画。要求逐例说明每种解释为什么通过或失败，尤其解释计数器反例。

### 3. 零位移处理

把碰撞样本视为关键判别条件，而不是坏数据。识别流程应区分“没有受控对象”和“受控对象被阻挡而未位移”；可以利用此前已建立的候选身份、静态外观、邻接障碍和局部变化，而不能把位移缺失直接当作身份否定。

### 4. 输出判别器与实验计划

child 应返回：候选排序步骤、每一步所需观测、冲突时的置信度/弃权条件、已知失败模式，以及后续安全动作能够区分哪些仍存假设。未来实验由主 agent 在自然推进且安全时执行，child 只分析随后得到的新帧。

### 5. 留出验证

若样本足够，构造方法时暂不展示至少一个片段，完成规则后再用该片段检验。若样本不足，则明确报告“尚不可判定”，并把下一个最小信息增益实验写清楚，不用流畅的总结替代证据。

## 是否创建 harness 组件

- **Subagent：暂不持久化。** 当前问题边界清晰，一次性干净上下文足够。只有同类识别工作持续出现、需要积累一套稳定分析上下文或多轮复核时，才保存持久 subagent 配方。
- **Skill：现在不创建正式 skill。** 先保留为候选方法。只有它有明确触发条件、逐步流程、弃权/失败条件，并通过至少一个未参与构造的片段或后续新观测验证后，才创建“受控对象识别”skill。skill 记录方法及适用条件，不记录本次轨迹。
- **Tool：暂不创建。** 若研究发现连通块差分、候选匹配和位移统计需要被反复、确定性执行，再创建一个受限的 **Pi task-local tool**，输入为明确的帧引用和参数，输出为结构化候选及度量；不让它自行决定哪个候选是“自己”。必须用计数器反例和碰撞样本验证实际语义输出后才装配。这里不涉及 MCP。
- **Memory：创建少量有有效期的事实记忆。** 当前 episode/level 内可记住已确认的候选身份、控制方向映射和当前未决假设；单个帧位置、地图局部和碰撞状态属于短期 state/level memory。只有跨 level 再验证的控制规律才升级为更长期记忆。研究结论及其证据引用应与原始短期事实分开。

## 有用结果的判据

研究结果只有同时满足下列条件才值得采用：

1. 给出可由另一个 agent 重复执行的步骤，而非观察摘要；
2. 能解释为什么“最大变化块”会在计数器样本上失败；
3. 明确处理碰撞导致的零位移，而不是依赖每步必移动；
4. 对每项结论附带来源片段，并区分观察、推断和猜想；
5. 有置信度或弃权分支，不在证据不足时强行认定；
6. 在留出片段或随后新观测上产生可核验预测；
7. 若建议 Pi task-local tool，必须给出确定性输入输出契约和语义测试案例。

只复述三次轨迹、换一种措辞声称“最大块通常是自己”，或提出无法由未来观测证伪的原则，都不算有用结果。

## 反馈与停止条件

child 首次返回后，主 agent只采纳已经有证据支撑且风险可控的部分；候选方法进入待验证状态，不立即当作事实。下一次自然出现安全且有区分度的动作机会时，主 agent收集一个新前后帧，将预测与结果反馈到同一研究线上。预测成功才考虑提升为 skill 或实现 Pi task-local tool；失败则要求 child 定位失败条件并修订或放弃方法。

满足以下任一条件即停止当前研究线：

- 方法通过预先约定的反例、碰撞例和至少一个留出/新样本，且剩余不确定性已有明确弃权规则；
- 证据表明仅凭现有帧无法区分候选，child 已给出所需的最小新增观测；此时暂停等待主 agent 的安全自然观测，而不重复分析；
- 连续一次修订仍不能解释同一反例，或输出持续退化为轨迹复述；
- 获取下一项证据需要冒不可接受的生命/行动预算风险；
- 研究继续消耗的预算超过其对当前决策的预期价值。

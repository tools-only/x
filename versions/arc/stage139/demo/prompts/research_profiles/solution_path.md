# Research focus: solution path

Investigate plausible ways to solve the delegated problem. Compare their
assumptions, evidence, failure conditions, and relevant costs. Identify observations
or experiments that would distinguish competing paths. Use only supplied or
accessible evidence; do not assume unobserved actions have succeeded.

Report supported options, conditions favoring each, and a discriminating next
test. If the evidence cannot select a path, explain the ambiguity instead of
inventing a uniquely correct action or precise outcome.

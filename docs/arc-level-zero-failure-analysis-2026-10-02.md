## 直接失败：错过了中央图案到外围方块的规则

公开当前棋盘的右下方中央 6×6 细节，每个 2×2 单元编码一个方块：

```text
0 2 2
0 8 0
0 2 2
```

历史模型识别的规则：外围对应 0 的位置应改为 8，对应 2 的位置保持 9。它依次点击 `(38,38)`、`(38,46)`、`(54,46)`、`(38,54)`，最后一次点击让 `levels_completed` 从 0 变为 1。这是公开动作和通关回执支持的目标，不来自隐藏 evaluator。

当前模型识别了块级切换，却持续试复制其他图案、镜像、AND、OR、XOR、多数投票等目标。按外围 8 个方块中心重算，55 步经过 28 个不同的外围配置，没有一次达到上述已验证目标。第 16、47 步各只差一个方块。第 44 步 RESET 后，第 45–47 步已正确改了左上、左中、右中；第 48 步却点了右下 `(54,54)`，而目标需要左下 `(38,54)`。

## 优化优先级

1. 合并重复旧窗口，限制同一证据批次反复要求父模型延期；研究/复盘提醒不能持续挤占正常任务行动。
2. 将迟迟无法解释的空间规则和目标反例交给有持续职责的研究 worker，阶段性返回核心结论；避免所有分析仍在父模型中反复生成。
3. 支持对公开图像的精确、可复用结构解析，以及目标预测与实际状态核对；不把本关解法预写入 prompt。
4. 用有限的竞争性检验和阶段性复核替代连续更换文字猜想，并保留已验证的坐标、状态和反例证据。
5. 单独排查环境调用与收尾超时。后续真实模型对照才可判断观测方案和策略优化的成本/成绩收益。

以上是诊断和候选优化顺序，不表示上述优化已实施，也不构成全组件 Self-Harness 闭环验收。

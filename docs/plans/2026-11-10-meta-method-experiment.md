# 可反射的 Meta 审阅方法实验

基线为 `11e32fd`。沿用同一 Pi 会话的 `self`、Mirror 属性授权、版本钉住和一次反射提交。目标依据为[自进化 Agent 设计宪法](https://chatgpt.com/library?file_id=libfile_9a04346b1da481919bc65b1d46a3b3d2&account_id=personal)。

## 问题与可证伪命题

基线的 `evolution_loop` 能在 WASI 中返回对单次草稿的分析结果。既有定向实验仅替换了领域检查器。六次普通任务没有发生自身反射。当前问题是审阅程序能否决定审阅什么、用哪些执行证据、实际运行什么试验，以及新版方法能否接管这一选择。

本轮只检验一个主要因素：**把对任务产物的评分函数扩为可反射的审阅方法，使其选择控制真实的后续审阅操作。** 若仅返回不同标签，宿主仍固定选择目标、证据或试验，则命题失败。该命题独立于是否改善具体 PPT、ARC 或代码任务。

## 设计和成本

- **运行结构。** 已注册的实际自身部分提供身份、类别、执行角色与版本。Meta 也在这一结构中。审阅分组与层级由方法生成，分组可跨类别，引用真实自身部分。用户对属性操作的授权继续显示在 Mirror 上。
- **运行证据。** 普通任务边界向当前 Meta 版本提供实际、有限、可引用的事实和自身结构。宿主不编码任务诊断或推荐改动。任务领域不同也沿同一执行入口。
- **方法与执行。** 旧、新 Meta 方法都由现有 CPython/WASI 运行。方法能选择范围和证据，并请求在受控环境中试验一个实际自身方法或结束本次审阅。运行时解释受限的动作合同，校验作用域、版本、参数、权限、资源边界，并执行选择。试验结果回到审阅路径，不自动改动生效定义。
- **决策与边界。** Agent 可以继续调查、改动、保持或暂缓。对 Meta 方法的提交仍使用 `reflect`，在下一次适用审阅中使用新修订。无效计划、越权或试验失败要有可见结果，任务仍能推进。新增审阅步骤需限制调用和数据体积，记录实际调用，避免额外强制模型轮次。

本次原型的 WASI 合同采用 `scopes` 与 `decision`。每个 scope 可命名自己的 `level`，并引用对象和证据。`complete` 结束审阅，`trial` 选择一个声明可试验的现有方法和一条版本化证据。宿主在同一修订下运行一次隔离试验，再把实际回执交给同一个 Meta 程序执行一次续审。试验不会写入活动定义，也不会推进真实环境。范围、验证标准和结论由方法自己给出。当前试验入口支持对现有方法重跑，尚不支持提交未生效的候选定义做配对试验。

## 运行前实验协议

在真实 Pi 0.87.0 会话中，先用默认 Meta 方法完成普通任务的一段工作并记录其实际审阅。反射修改 Meta 方法，然后在可比较输入上运行，要求新版能改变审阅对象、证据选择或所请求的试验，且真实调用与返回结果均带版本证据。至少一个后续案例使用不同任务素材以检查通用接口。校验错误、权限、预算、陈旧引用和未修改等负例。

脚本提供者用于功能和接线证明。若运行独立 GPT‑6 Luna high 定向实验，明确要求改变审阅方法，照实记录指令，不能算自主采用。普通任务如无相应机会或没有修改，照实记录。没有匹配的多次任务和成本对照时，净收益维持未验证。

独立定向实验以工程发布说明和研究提纲为两组素材。只授予 `evolution_loop` 写权限，普通任务方法保持原样。使用素材 A 的首次审阅与原样重跑作因果对照，再用素材 B 验证接口在另一种素材下仍然可执行。要求新程序跨类别分组，选较早的版本化证据，在试验续审里使用真实回执。使用原有本地模型中继，单会话最多 18 次回复，单次等待 240 秒，不调用付费端点。

## 实现与验证

- [`LiveSelfSession`](../../demo/live_self_core.ts) 从生效修订生成自身结构，输入同一修订的 Meta 方法，并附上当前和最多三条先前草稿的原始执行证据。模型 Mirror 上保留属性授权和方法合同。WASI 只看到有界结构和证据，不获得修改授权引用。
- 宿主验证 scope 对象和证据引用，执行方法所选的一次隔离试验，再将结果交给同一修订的 Meta 方法续审。不同类别可以进入同一 `level`。试验、续审和交付有独立记录，试验失败不提交自身变更，续审超出次数时保留已取得的回执，任务草稿仍可提交。
- GPT‑6 Luna high 实施了原型与验收用例。Node/WASI 5 项、pytest 12 项通过。覆盖受保护目标、陈旧证据、超预算和禁止第二次试验。实际 Pi 脚本用例选用 `evidence-1@r1`，续审程序比较实际试验输出与原记录，得出不同结果。测试确认类别不同的两个方法可以在同一组，并检查后续另一类素材的任务提交。

### 独立 Luna high 定向诊断

同一 Pi 会话 6 次实际模型请求，Mirror 修订依次为 `1, 1, 2, 2, 2, 2`。只提交一次反射，目标为 `evolution_loop`。任务方法没有写授权，首次与重跑 A 的输入和草稿相同。

| 情境 | 实际审阅行为 |
| --- | --- |
| 素材 A，`r1` | 只选择任务方法，审阅完成，无试验。 |
| 原样重跑 A，`r2` | Luna 编写的新方法把普通任务方法和 Meta 方法放进同一个 `method` 层级，执行一次实际 WASI 试验，并在收到回执后完成续审。 |
| 素材 B，`r2` | 同一新 Meta 方法再次选择跨类别分组并执行试验和续审。任务提交成功，模型手工补齐了 B 的产物。 |

模型未完成定向要求的全部细节。两次都选了当前证据，续审程序只依据回执是否存在，没有解释试验输出。脚本用例验证了历史证据选择与结果内容进入续审，Luna 运行只验证模型编写和切换 Meta 后能控制审阅调用。该运行经本地模型中继，不是模型原生 API。141,533 字节为中继累计输入，约 137 秒为累计等待，均不用于推算 token 或净收益。[原始运行记录](../../runs/meta-luna-directed-20261110/trace.jsonl)

| 证据层级 | 结论 |
| --- | --- |
| 功能与权限 | 通过本轮检查。 |
| 真实接线 | 实际 Pi 和 WASI 已证明 Meta 反射改变后续审阅范围与试验。脚本证明续审能使用输出内容。 |
| 自主采用 | 本轮未检验。Luna 任务明确要求修改 Meta。 |
| 净收益 | 本轮未检验。没有同预算重复对照。 |

保留在实验扩展上。两类文本素材使用同一接口，不能外推到生产 ARC/PPT、真实 Skill/Tool 组合、跨会话恢复或多步骤候选实验。生产适配和[认知连续性](../deferred-research-todos.md)的验收状态不变。

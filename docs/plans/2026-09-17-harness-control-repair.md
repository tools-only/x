# Deterministic harness control repair

Approved scope: source repairs and mock ARC verification; existing live runs are not restarted.

The runtime owns identity, version selection, canonical review shape, legal handoff
transitions, retry budgets and failure correlation. The model owns reasons,
hypotheses, candidate bodies, validation proposals and interaction-mode choices.
An omitted identity may bind only a unique eligible object. Explicit invalid or
stale identities never silently select another object. Ambiguity returns candidates.

Implementation sequence:

1. Add behavioral regressions for partial review normalization, evidence classes,
   identity selection, handoff reading/reactivation and operation correlation.
2. Implement shared deterministic contracts and integrate public tool schemas,
   recovery responses and status templates.
3. Repair handoff lifecycle, replayable review commits and bounded action gates.
4. Verify native Pi fixtures and the ARC bridge/parent/broker/child/router/action
   path with mocked provider/environment boundaries and later parent turns.

Omitted review components are recorded as runtime-deferred, never model conclusions.
Historical evidence must exist in the same task; at least one current-window
reference is required for transition analysis. No semantic validation is invented.
Deferred handoffs default to manual reactivation; optional action-count conditions
are deterministic. Safety admission remains separate from soft review budgets.

Deferred backlog A/C/D applies: keep policy in the Agent runtime, preserve exact
evidence and state across parent/child handoff and recovery. This change does not
implement independent blind research or claim provider/benchmark performance.

# 迟到研究报告的使用决策

当前权威状态是 observation:24、level 2。报告基于 level 1、observation:18；其 RIGHT, RIGHT, UP 路线已失去适用依据，不执行、不排队，也不以旧地图目标覆盖当前计划。报告保留来源、快照和关卡标记。

跨帧动作对照方法具有复用潜力，但两段构造帧只能证明示例可运行，尚不能证明真实场景有效。将其登记为实验性方法，创建隔离、默认禁用的候选 harness；暂不装配进主 agent 的行动决策链，不赋予其发出动作的权限。候选输入为同一关卡内真实的动作前后观测及对应动作，输出受控实体候选、证据和不确定性；跨关卡、缺帧或证据冲突时必须弃权。具体实现尚未由本决策执行。

请求一次有明确上限的研究实验：优先使用现有可用的真实观测与动作记录，检查方法能否区分受控实体、自主移动对象和镜头位移。把构造帧作为开发样例，另用未参与调试的真实片段验证；旧关卡通过不代表 level 2 通过。若当前关卡没有足够的已记录帧，等待主 agent 原计划动作产生新观测，以只读影子方式评估。不得重放环境、回退历史或为了研究默认消耗额外动作；预算不足则延后实验。

评估关注实体识别是否正确、错误归因与弃权情况、对遮挡或无位移等歧义的处理，以及计算与行动成本。使用可独立核实的环境信息或人工标注作参照，不能用方法自己的结论验证自己，也不能仅凭研究任务完成或程序无报错判定成功。缺少可靠参照时，结论只能是待验证。

只有在独立真实片段上取得可信证据，且在 level 2 的影子运行中显示适用、开销可接受后，才考虑将 harness 作为辅助观测工具装配；初期保留弃权及快速禁用机制。研究返回时再次核对当前关卡与 observation，旧路线始终不因方法验证通过而恢复有效。本次只作决策，不执行动作，不宣称方法或完整链路已验收。

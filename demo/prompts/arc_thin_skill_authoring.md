A skill is a directory skills/<name>/ with SKILL.md: frontmatter name (the directory's name), description (what it does and when it applies: the line shown under HARNESS and the only text that decides whether the body is read; quote it if it contains a colon, or the header does not parse), and, if it should be shown at an event, metadata: {trigger: level_start} or {trigger: stall}; then the body, steps in the imperative, short. Put deterministic work in a script beside it (skills/<name>/scripts/<file>.py), run from python, not in prose. One procedure per skill; what you found true of the game is memory, not a skill.

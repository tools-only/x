# Research focus: component

Determine what the selected component actually does, where it applies, and where
it fails. Inspect its exact version, intended behavior, and available execution
evidence. Compare claimed behavior with observed results; examine relevant
counterexamples, input conditions, limitations, and cost.

Distinguish implementation defects from incorrect use or unsupported assumptions.
Report the supported behavior and the evidence needed for any proposed revision.
The component's existence or registration alone is not evidence that it works.

# Select and use exact components

Main chooses relevance; runtime validates versions, scope, permissions and budget. task_harness_create publishes and installs exact versions by default, retaining eligible selected components and valid prompt contributions; obsolete selections are listed in the cleanup receipt. assembly=false stages only. task_harness(change) without assembly remains pool-only. An explicit assembly={expected_assembly_revision:N,selected_resource_refs:[existing exact refs to retain]} selects this call's written versions plus those refs using strict CAS. If writing succeeds but selection fails, retain the written versions and repair assembly without recreating them.

For existing components, use task_harness(action=assemble) with current expected_assembly_revision, selected_resource_refs and decision={basis_refs,reason,expected}. Keep other needed selections. Receipts/current assembly provide revision and exact refs; inspect only if needed information is absent or stale. Omitted prompt_contributions retain existing contributions; [] clears them. An unchanged composition persists across parent turns; ordinary ARC actions do not need reassembly. No assembly means an empty selection.

Follow receipt use entries: apply selected Skill instructions already in context; load_if_needed recovers a missing body. Invoke the versioned Tool and check its value. Prefer ordinary delegate_task for one-off analysis; delegate a saved Subagent when its role should be reused. Scoped Skill read preserves composition; focus intentionally narrows it. Memory capture select=true saves and selects its text; archive-only remains optional. System Prompt refreshes on the next provider request. Cite applied refs and compare predictions with outcomes; exposure or citations alone do not prove help.

task_prompt is an output channel, not a sixth component. Parent-selected exact-source contributions may express policy, methods, plans, hypotheses, state or research from authorized resources. Research output never becomes guidance automatically. Keep uncertainty and counterevidence. Full details: contract(topic=assembly,section=all).

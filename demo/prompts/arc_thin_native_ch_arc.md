## ARC observation contract
The working view contains the authoritative current state, available actions and recent action results. By default it also contains the raw grid, observations since the last query and corresponding images. If your Agent-authored observer opts into `# semantic_view: on` and returns usable facts for the current state, those facts replace raw grids and images for that request; the exact current grid remains available in the named `data/frames/<step>.json` file. If the observer is missing, stale, empty or fails, raw grids and images are shown again. Action results report state/score changes and changed-cell counts and bounds; selected intermediate frames may also appear when raw observation is active.

Coordinates are zero-based from the top-left: `x` increases right and `y` down. The `arc_action` tool schema describes accepted actions and arguments. Each action produces a receipt.

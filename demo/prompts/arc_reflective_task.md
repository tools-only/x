The task is to complete the interactive environment task. The current observation is canonical and includes the full public grid and image, the available actions, level progress, and remaining action limits. `arc_action` sends one concrete action through the authorized parent environment boundary. Native components are optional Agent resources; their sources and saved versions are ordinary readable files under `components/<kind>/<name>/`. Parent and child requests share the same run budget. The environment and task action boundary cannot be changed by a child.

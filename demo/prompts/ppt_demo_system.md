# Self-Harness

The user task outcome, scope, and constraints define success. Component modification is optional and is not task success. `reflect_component` owns component inspection and publication. Published tools and subagents are Pi tools under their logical names; skills appear in Pi?s explicit workspace skill index and are ordinary readable files. Prompts, memory, and active process context enter provider requests. The environment adapter supplies task actions and facts; workspace confinement, provider authorization, budget, and deadline remain fixed boundaries.

# Task-local components

Main authors and chooses by the task's missing operation, uncertainty or reusable context; component counts are not a goal. Research is optional. A first-use or local candidate may be untested: state its uncertainty and test what budget and access permit. Admission does not certify meaning, correctness or benefit.

- Memory holds a scoped fact, hypothesis or plan. For short text use task_memory_pool(action="capture",items=[{key,content,scope}],select=true) to save and select exact versions for current context; omit select or use false to archive only. Formal create/change supports {component:"memory",key,content,atom:{subject,predicate,value},validity:{scope:"task|episode|level|state"}}. Choose one actual scope; runtime binds omitted identifiers. Later choose any exact subset/contribution with assemble. Current frame, position and budget already come from runtime.
- System Prompt guides decisions. Candidate: {component:"system_prompt",name,content,scope:"when this applies"}. Selected content is refreshed on the next provider request in the same run. Descriptive scope text is not automatic expiry; exact scope task|episode|level|state binds validity. Include a reconsideration condition. Facts do not become directives automatically.
- Skill is a procedure for the model: inputs, steps, decisions, outputs and stopping. Write the steps and apply them directly when already in context; read only to recover missing instructions. Computation belongs in a Tool. skill-creator is optional.
- Tool performs an executable computation with defined inputs and outputs. Author its complete supported program; trial can return a result in the creation call. Check actual values; tool-creator is an optional reference.
- For temporary analysis prefer delegate_task(task,output_contract?,stop_when?,budget?,tools?,context_recipe?): one invocation, no registration. Budget can tighten time, tool calls, reported tokens and length attempts. Save a Subagent only for a reusable responsibility; author its instructions/tools and optionally run it on creation. Inspect semantic answers, cost and limitations. subagent-creator is optional.

If task_memory_pool or delegate_task is hidden, activate the needed exact name with task_harness(action="activate",enabled_tools=["<tool name>"]); the active schema supplies its fields. Availability depends on the current runtime. Auto-Research being disabled does not disable an available ordinary delegate.

Publish and install with task_harness_create; assembly=false stages only. task_harness(change) omission remains pool-only. Optional assembly={expected_assembly_revision:N,selected_resource_refs:[existing refs to retain]} selects written versions plus retained refs using strict CAS. If selection fails, repair without recreating saved versions. Receipts give exact versions and use entries; composition persists until changed. Apply Skill steps, Tool values or delegated conclusions to a task decision and inspect feedback. Creation, exposure and agreement alone prove no benefit.

Declare exact depends_on_refs for validity dependencies and supersedes_refs for replacements; basis_refs alone are historical evidence. Keep canonical bodies and projections consistent. Revise, suspend or retire contradicted guidance. Full details: contract(topic=components,section=all).
